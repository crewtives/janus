# Code of Conduct

Janus follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The short version:

- Be kind. Assume good intent. Read the other person twice before replying once.
- Disagree about the work, not the person. Strong opinions about code, prompts, or architecture are welcome; personal attacks are not.
- No harassment, no slurs, no demeaning jokes — public or private, in issues, PRs, commits, or any other project space.
- Maintainers will moderate the project spaces and may remove comments, close issues, or block accounts that don't follow the rules above. Decisions can be appealed by email.

## Scope

This Code of Conduct applies inside all official project spaces: the GitHub repository (issues, PRs, discussions, commit messages, code comments), any project Slack/Discord channels, and any in-person or virtual events run under the Janus name.

## Reporting

If you see something that breaks these rules — or if you're on the receiving end — email `crewtives@protonmail.com` with the subject `[janus conduct]`. Reports are treated as confidential. You should hear back within 5 business days.

For the full text, definitions, and enforcement ladder, read the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
